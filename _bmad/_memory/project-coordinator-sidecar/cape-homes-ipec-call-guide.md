## SLIDE 7: Process Discussion Preview — What Each Session Will Look Like

### What to Cover
This is where you set expectations for the collaborative work ahead. Explain what the process discussions will look like and what you need from them.

### Talking Points

> "After today, we'll schedule focused process discussions — usually 30 to 45 minutes each — where we deep-dive into one area at a time. Here's how those sessions work:"

1. **I come prepared** — I'll have a draft framework based on what I already know from today and the SOW
2. **You walk me through reality** — "When a new email comes in, what do you do? Show me. Walk me through a real example."
3. **We build together** — I document the steps, decision points, and escalation rules as we go
4. **You review the draft** — I send you the SOP within a few days. You mark what's right, what's wrong, and what's missing.
5. **We finalize** — One more pass, then it goes into the playbook.

### Process Discussion Schedule (Proposed)

| Session | Focus Area | Key Outcomes |
|---------|-----------|--------------|
| **Session 1** | Email Management | Inbox categories, handling rules, draft response templates, escalation rules, tone guide |
| **Session 2** | Calendar Management + Task Management | Scheduling rules, approval workflow, daily task review process, priority system |
| **Session 3** | Pre-Purchase Checklist + Post-Sale Checklist | Step-by-step admin procedures for both, utility touchpoints, owner review gates |
| **Session 4** | Utilities Workflow + Contact Tracking | Utility setup/transfer/cancel process, vendor contacts, account tracking system |
| **Session 5** | Stoplight Report + Daily Cadence | Finalize report format, delivery time, review process, EA daily rhythm |
| **Session 6** | Playbook Review | Full walkthrough of the consolidated EA Playbook before sourcing |

> "Each session builds on the last. By the time we're done, you'll have a complete playbook that any qualified EA can pick up and run — and if the EA ever leaves, the next one inherits the same system."

### Questions

47. Does this cadence work for you? Can you commit to 30–45 minutes, two to three times a week, for the next two to three weeks?
48. Is there a specific day/time that works best for these process sessions?
49. Between sessions, I may send you questions via email — is that okay, or do you prefer everything in live calls?
50. Are there any process areas you want to tackle first because they're the most painful right now?
