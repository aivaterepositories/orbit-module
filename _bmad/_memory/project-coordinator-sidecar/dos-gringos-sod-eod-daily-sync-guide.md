## Overview

Three daily touchpoints keep the VA and Walker aligned:

| Touchpoint | When | Format | Purpose |
|------------|------|--------|---------|
| **Daily Sync** | Morning (start of shift) | Live call with Walker (~30 min) | Plan the day together, set expectations, share urgent info |
| **Start of Day (SOD) Report** | Before or after daily sync | Written (GHL notes, email, or chat) | VA's planned priorities for the day |
| **End of Day (EOD) Report** | End of shift | Written (GHL notes, email, or chat) | Summary of outcomes, blockers, next-day plan |

---

## 1. Daily Sync — Morning Standup with Walker

### Purpose
A quick morning check-in so Walker and the VA start the day on the same page. Walker sets expectations, VA shares priorities, and both align on what matters most.

### Format
- **Duration:** ~30 minutes
- **Time:** Early morning (CST) — start of VA's shift
- **Method:** Phone call (Walker can be driving, walking, or at his desk — doesn't need to be on a computer)

### Agenda

**VA shares:**
1. Priority leads for today (from SOD report)
2. Any callbacks or commitments from yesterday
3. Any leads that need Walker's input or decision
4. Blockers or questions

**Walker shares:**
1. Any new priorities or urgent leads to focus on
2. Updates from Roar, acquisitions team, or Colton
3. Any leads Walker wants the VA to deprioritize or skip
4. Reminders or context for specific leads

### Ground Rules
- Keep it focused — this is a standup, not a deep dive
- If a topic needs more than 5 minutes, schedule a separate call
- VA should have the SOD report ready before the sync
- Walker can redirect priorities based on what he's hearing

## 2. Start of Day (SOD) Report

### Purpose
Before starting outreach, the VA documents their planned priorities so Walker has visibility into how the day will unfold. This replaces the need for a separate VA pipeline.

### Template

```
START OF DAY REPORT — [Day], [Date]
Lead Manager VA: [Name]

—

PIPELINE CHECK
- New Leads in Queue: [#]
- PPC Pipeline Active: [#]
- Outbound Pipeline Active: [#]
- Tasks Due Today: [#]
- Overdue Tasks: [#]

—

TODAY'S PRIORITIES

PPC Leads (Priority 1):
1. [Lead Name] — [Stage] — [Action: e.g., Follow-up call, awaiting response]
2. [Lead Name] — [Stage] — [Action]

Outbound Leads (Priority 2):
1. [Lead Name] — [Stage] — [Action]
2. [Lead Name] — [Stage] — [Action]
3. [Lead Name] — [Stage] — [Action]

—

CALLBACKS / COMMITMENTS
1. [Lead Name] — Promised to call back at [time] re: [topic]
2. [Lead Name] — Sending [document/info] today

—

QUESTIONS FOR WALKER
1. [Question or decision needed]

—

NOTES
[Anything else — e.g., automation triggered overnight, new leads from Speed Dial, etc.]
```

### How to Use
- VA fills this out before the morning daily sync
- Use it as the sync agenda — walk Walker through each section
- After the sync, update priorities if Walker redirects anything
- Keep a copy in GHL notes or shared doc for the record

## 3. End of Day (EOD) Report

### Purpose
Summary of the day's activity so Walker knows what happened, what moved forward, and what's planned for tomorrow. This is the VA's accountability report.

### Template

```
END OF DAY REPORT — [Day], [Date]
Lead Manager VA: [Name]

—

TODAY'S ACCOMPLISHMENTS

PPC Leads:
1. [Lead Name] — [Outcome: e.g., Spoke with seller, moved to Triaged. Motivated — timeline is 30 days.]
2. [Lead Name] — [Outcome: e.g., No answer x2, left voicemail, set task for tomorrow AM]

Outbound Leads:
1. [Lead Name] — [Outcome]
2. [Lead Name] — [Outcome]
3. [Lead Name] — [Outcome]

—

KEY METRICS
- Total Calls Made: [#]
- Contacts Reached: [#]
- New Leads Worked: [#]
- Leads Advanced (moved to next stage): [#]
- Appointments Set: [#]
- Tasks Completed: [#]
- Tasks Created (for tomorrow): [#]

—

LEADS TO WATCH
1. [Lead Name] — [Why: e.g., Very warm, wants to meet this week. Needs Walker's input on offer.]
2. [Lead Name] — [Why: e.g., Responded to automation, seems interested but guarded.]

—

TOMORROW'S PLAN
1. [Priority action]
2. [Priority action]
3. [Priority action]

—

BLOCKERS / ISSUES
1. [Blocker or issue — e.g., Couldn't reach lead after 3 attempts, automation still texting after response]
2. [None — if clear]

—

HANDOFF NOTES FOR WALKER
[Any leads that need Walker's direct attention, decisions, or acquisitions team involvement]
```

### How to Use
- VA fills this out at the end of every shift
- Delivered to Walker via agreed channel (email, GHL, or chat)
- Walker reviews before the next morning's daily sync
- Any "Leads to Watch" or "Handoff Notes" should be discussed in the morning sync

## Why This Replaces a Separate VA Pipeline

Walker initially proposed creating a new pipeline exclusively for VA-managed leads. Fiona recommended SOD/EOD reports instead because:

1. **Less setup overhead** — no pipeline restructuring needed during an already-busy transition
2. **Same visibility** — Walker sees exactly what the VA is working on every day
3. **Performance tracking** — EOD metrics (calls made, contacts reached, leads advanced) measure VA effectiveness directly
4. **Flexibility** — works regardless of how GHL pipelines evolve with Roar's input
5. **Accountability** — daily written reports create a paper trail

If Walker later decides a separate pipeline is still needed, it can be added once the VA is onboarded and the process is stable.
