## Agenda & Discussion

### 1. LinkedIn Scraper Tool Demo — Marky

Marky presented a custom-built LinkedIn scraper tool designed to accelerate lead generation and contact capture.

**How it works:**
- User inputs: **Industry**, **Location**, **Number of results per role**
- Tool automatically searches LinkedIn via MCP integration (opens Google Chrome, runs scrape)
- Outputs: Name, Title/Role, Location, Direct LinkedIn profile link
- Generates a **downloadable CSV file**

**Baseline roles searched:** CEO, CFO, CTO, Business Development Manager
- Additional roles can be added upon request to Marky

**Demo example:**
- Industry: Real Estate | Location: Philippines | Output: 10 per role
- Result: 40 profiles total (10 per role x 4 roles)
- Sample result: Sheila Lobien, CEO, Lobien Realty Group
- Can scale up to 50+ per role (200+ total profiles)

### 2. Scraper as a Sellable Product — Fiona

Fiona identified the scraper as a **standalone product** Aivate can offer to clients:

- Can be **customized** based on client's ICP/targeting needs (industries, roles, locations)
- Currently in **free/basic mode** — pulls LinkedIn profiles only
- **Enhancement path:** Apollo subscription would enable pulling email addresses and contact numbers
- For Aivate's internal use, LinkedIn profiles are sufficient (contact info available via LinkedIn profile click-through)

### 3. Lead Tracking Workflow Setup — Fiona & Marlon

Marlon requested a structured follow-up workflow (similar to GHL). Fiona set up a **Trello board** live during the meeting.

**Trello Board:** Aivate International BDM

**Funnel Stages (columns):**

| Stage | Description |
|-------|-------------|
| Not Contacted | Fresh leads from scraper |
| Contacted | Connection request sent |
| First Follow-up | 3 days after acceptance — send initial message |
| Second Follow-up | 1 week after first attempt (if no reply) |
| Third Follow-up | 2 weeks after second attempt |
| Interested | Lead engaged — book discovery call |
| Dead | No response after third follow-up |

**Card Template Fields:** Name, Company, Role, Need/Problem, Solution

**Lead Temperature Labels:**
- **Hot** — Urgent/immediate need, close within 1 week
- **Warm** — Interested, longer timeline
- **Cold** — Low engagement

**Regional Labels (Marlon to create):** US, AU, EU

**Agreed Follow-up Cadence:**

| Step | Timing |
|------|--------|
| Send connection request | Day 0 |
| Wait for acceptance | 3 days |
| Send initial message | Upon acceptance |
| First follow-up | 1 week after first attempt (no reply) |
| Second follow-up | 2 weeks after second attempt (no reply) |
| Move to Dead | After third follow-up with no response |

**Reporting:** Weekly, offline via email or Discord. Calls scheduled only when questions arise.
