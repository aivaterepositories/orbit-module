```
- User management

- Live pipeline metrics — what each number means
- Jobs by stage breakdown, active work orders, pending change orders

- Set billing handoff status to "Ready"

- Connects directly to SOV and reconciliation metrics on the dashboard
```

## SESSION 3 — Manager Training (7 Managers)

```
Create a professional training presentation with exactly 10 slides for a CRM manager training session. The company is Temp Power Systems (TPS), an electrical contracting company. The presentation is by Aivate Solutions, who built the CRM. This is Session 3 of 4 — for the 7 managers including Wayne (Project Manager).

Style: Clean, modern, professional. Use a dark blue and white color scheme. Keep slides visual with minimal text — icons, screenshot placeholders, and short bullet points.

App URL: https://temp-power-system.vercel.app

Slides:

1. TITLE SLIDE
Title: "TPS CRM — Manager Training"
Subtitle: "Session 3 of 4 — Jobs, Scheduling & Crew Assignment"
Footer: "Presented by Aivate Solutions"

2. YOUR ROLE IN THE CRM
As a manager, you focus on:
- Monitoring jobs synced from Salesforce
- Scheduling work orders
- Managing the work order calendar
- Assigning crews to jobs
You do NOT handle: change order approvals, billing, or user management (that's admin-level)

3. LOGIN & LANDING PAGE
- URL: https://temp-power-system.vercel.app
- Use the email + password provided by admin
- You'll land on the Jobs view
- This is your home base — everything starts here

4. JOBS VIEW & JOB DETAIL
- All jobs synced from Salesforce appear here
- Filter by: Stage, Owner, Status
- Click any job to drill into the details
- Inside a job: SOV (read-only), tasks assigned to you/your crew, work orders, notes, attachments
- You can review everything but cannot approve change orders or manage billing

5. SCHEDULING A WORK ORDER
- From the job detail page, click "Create Work Order"
- Set scheduled start and end dates (required)
- Save — system auto-assigns a work order number
- Pro tip: Create WOs 2-3 weeks ahead using "Pending" status

6. WORK ORDER STATUS FLOW
Show a horizontal flow diagram:
Pending → Ready for Field Execution → In Progress → Complete
- Pending: Visible on calendar, hidden from crew portal
- Ready for Field Execution: Crews can now see it in their mobile app
- In Progress: Crew has clocked in and is working
- Complete: Work finished, ready for billing review

7. WORK ORDER CALENDAR
- Week and month views available
- Color-coded by work order status
- Drag and drop events to reschedule
- Spot conflicts: overlapping crew assignments, double-bookings
- One unified view of all scheduled work across all jobs

8. ASSIGNING CREWS & MATERIALS
- On a work order, open the Crew Assignment builder
- Add crew members by Employee ID, set the crew lead
- Save — crew members see the assignment on their phones
- Crews only see work orders with "Ready for Field Execution" status or later
- Each work order also shows materials/equipment needed — if something is missing or wrong, flag it before the crew deploys

9. WHAT TO FLAG DURING THE PILOT
- Missing jobs (should have synced from Salesforce but didn't appear)
- Scheduling conflicts the calendar doesn't catch
- Numbers that look off in SOV or work order details
- Anything slow, confusing, or that takes too many clicks
- Support: Message Cob directly

10. Q&A
Title: "Questions?"
Subtitle: "You're the ones using this daily — tell us what needs to be better."
Contact: "Support: Message Cob directly"
```
