**Instructions:** This tracker is the VA's daily working document. Every outreach attempt, every conversation, every outcome gets logged here. Update it in real time — do not batch updates at end of day.

---

## Tracker Structure

### Section A: Client Information

| Column | Description |
|--------|-------------|
| **Firm Name** | Name of the architectural firm or developer |
| **Contact Person** | Primary person to reach out to |
| **Title** | Their role at the firm (Principal, Associate, PM, etc.) |
| **Phone** | Direct phone number |
| **Email** | Direct email address |
| **Firm Size** | Small / Medium / Large |
| **Project Types** | What they typically do (custom homes, schools, commercial, mixed-use, etc.) |

### Section B: Relationship History (from Proposal Summary)

| Column | Description |
|--------|-------------|
| **Last Proposal Date** | When KFA last submitted a proposal to this firm |
| **Last Proposal Project** | What the last proposal was for |
| **Last Proposal Fee** | Fee quoted (reference only — confidential, do not share) |
| **Proposal Won/Lost** | Did KFA win or lose that proposal? |
| **Reason Lost** | If lost — why? (Fee too high, went with competitor, project cancelled, etc.) |
| **Relationship History** | Brief summary of the overall relationship (e.g., "71 proposals since 1995 — 30-year relationship") |

### Section C: Outreach Activity Log

| Column | Description |
|--------|-------------|
| **Outreach Status** | Dormant / Contacted / Engaged / Meeting Set / Proposal Requested / Won / Lost / Unresponsive |
| **Outreach 1 Date** | Date of first outreach attempt |
| **Outreach 1 Channel** | Phone / Email |
| **Outreach 1 Outcome** | Connected / Voicemail / No Answer / Email Sent / Replied / No Response |
| **Outreach 2 Date** | Date of second attempt |
| **Outreach 2 Channel** | Phone / Email |
| **Outreach 2 Outcome** | Same options as above |
| **Outreach 3 Date** | Date of third attempt |
| **Outreach 3 Channel** | Phone / Email |
| **Outreach 3 Outcome** | Same options as above |
| **Outreach 4 Date** | Date of fourth attempt (final follow-up email) |
| **Outreach 4 Channel** | Email |
| **Outreach 4 Outcome** | Replied / No Response |

### Section D: Meeting & Opportunity

| Column | Description |
|--------|-------------|
| **Meeting/Lunch Scheduled** | Yes / No |
| **Meeting Date** | Scheduled date |
| **Meeting Outcome** | What came out of the meeting (project discussed, relationship renewed, no opportunity yet, etc.) |
| **Has Active Project** | Yes / No |
| **Project Details** | If yes — project type, size (sq ft), location, timeline |
| **Proposal Requested** | Yes / No |
| **Proposal Sent Date** | When KFA sent the proposal |

### Section E: Follow-Up & Priority

| Column | Description |
|--------|-------------|
| **Next Follow-Up Date** | When the VA should reach out again |
| **Priority** | Hot / Warm / Cold |
| **Notes** | Free-text field for anything else — context, intel, Jack's instructions |

---

## Status Definitions

| Status | Meaning |
|--------|---------|
| **Dormant** | On the list but not yet contacted |
| **Contacted** | Outreach attempted — no meaningful conversation yet |
| **Engaged** | Had a conversation — relationship is active |
| **Meeting Set** | Lunch or meeting scheduled with Jack |
| **Proposal Requested** | Client has a project and wants a proposal from KFA |
| **Won** | KFA won the proposal — project awarded |
| **Lost** | KFA did not win the proposal — capture reason |
| **Unresponsive** | Completed 2 full outreach cycles with no response — revisit quarterly |

---

## Priority Definitions

| Priority | Meaning |
|----------|---------|
| **Hot** | Long history with KFA, high-volume firm, or expressed active interest. Contact immediately and prioritize. |
| **Warm** | Known relationship, some history, but no immediate signal. Standard monthly cadence. |
| **Cold** | New or minimal history. Lower priority — outreach after Hot and Warm are covered. |
